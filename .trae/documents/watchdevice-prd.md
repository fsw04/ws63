## 1. 产品概述

WatchDevice 健康监测手环 UI — 一款 480×320 横屏嵌入式健康监测设备界面，通过 SLE 星闪协议连接网关，实时展示佩戴者健康体征数据与连接状态。

- 目标用户：养老院/医院中的老年佩戴者及护理人员
- 核心价值：一目了然地展示健康体征数据，实时反馈 SLE 连接状态与数据发送情况

## 2. 核心功能

### 2.1 功能模块

1. **主界面**：健康体征数据展示 + SLE 连接状态 + 设备信息

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主界面 | 健康体征卡片 | 展示姓名、血压、血糖、身高、体重、BMI 等体征数据 |
| 主界面 | SLE 连接状态 | 显示连接/断开状态、网关 MAC、RSSI 信号强度 |
| 主界面 | 设备信息 | 显示本机 MAC 地址、设备 ID |
| 主界面 | 数据发送状态 | 显示最近一次数据发送时间与结果 |

## 3. 核心流程

```mermaid
flowchart TD
    "开机" --> "SLE扫描网关"
    "SLE扫描网关" --> "发现网关"
    "发现网关" --> "连接网关"
    "连接网关" --> "配对认证"
    "配对认证" --> "采集健康数据"
    "采集健康数据" --> "通过SLE发送数据"
    "通过SLE发送数据" --> "更新UI状态"
    "连接网关" --> "连接失败"
    "连接失败" --> "重新扫描"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色医疗科技风 — 深蓝黑底 (#0A0E1A)，搭配医疗绿 (#00E5A0) 作为健康状态色
- **辅助色**：警告黄 (#FFB020)、危险红 (#FF4D6A)、信息青 (#00D4FF)
- **按钮风格**：圆角 6px，扁平化，状态色填充
- **字体**：数字用等宽风格，标签用简洁无衬线体
- **布局风格**：左右分栏 — 左侧健康体征大卡片，右侧连接状态与设备信息
- **图标风格**：线性图标，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主界面 | 健康体征区（左） | 姓名+电话卡片、血压大数字显示、血糖/身高/体重/BMI 网格卡片 |
| 主界面 | 连接状态区（右上） | SLE 连接状态指示灯、网关 MAC、RSSI 信号条、数据发送状态 |
| 主界面 | 设备信息区（右下） | 本机 MAC 地址、设备 ID、运行时间 |

### 4.3 响应式

- 固定 480×320 横屏布局，不做响应式适配
- 触摸优化：按钮最小点击区域 28×28px
